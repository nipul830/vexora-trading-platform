# Vexora Trading Platform

Starter trading-chart foundation for Vexora.

## Run
npm install
npm run dev

Features in this starter:
- Candlestick chart
- Volume
- Crosshair
- Mouse/touch pan
- Pinch zoom support
- Timeframe UI
- Responsive Android-tablet layout

Market data is demo data for now. Production data providers will be added through a provider adapter layer.
